دارک‌مود وردپرس و المنتور با نگاشت رنگ دلخواه.

== نصب ==
1. پوشه darkso را در wp-content/plugins کپی کنید.
2. از پیشخوان وردپرس افزونه Darkso را فعال کنید.
3. تنظیمات → Darkso رنگ‌ها را مشخص کنید (از رنگ روشن به رنگ دارک).
4. روی سایت یک دکمه/لینک با کلاس darkbouttom بگذارید.

== استفاده ==
کلیک روی هر عنصری با کلاس darkbouttom سایت را بین حالت روشن و دارک سوییچ می‌کند.
ترجیح کاربر در مرورگر ذخیره می‌شود.
