دارک‌مود وردپرس و المنتور با نگاشت رنگ دلخواه، ویجت‌های لایت/دارک و نمایش شرطی با کلاس‌های Lightshow و Darkshow.

== نصب ==
1. فایل زیپ را از «افزونه‌ها ← افزودن ← بارگذاری افزونه» نصب کنید (یا پوشه darkso را در wp-content/plugins کپی کنید).
2. افزونه Darkso را فعال کنید.
3. به «تنظیمات ← Darkso» بروید و رنگ‌ها را مشخص کنید (از رنگ روشن به رنگ دارک).
4. روی سایت یک دکمه/لینک با کلاس darkbouttom بگذارید (یا ویجت «سوییچ دارک‌مود» را استفاده کنید).

== شروع سریع ==
۱) رنگ‌های روشن سایت را در تب «رنگ‌ها» به رنگ‌های دارک تبدیل کنید و ذخیره بزنید.
۲) یک دکمه با کلاس darkbouttom بسازید.
۳) روی دکمه کلیک کنید؛ انتخاب کاربر در مرورگر او ذخیره می‌شود.

== نحوه‌ی اضافه کردن کلاس در المنتور ==
المنت را انتخاب کنید ← پیشرفته (Advanced) ← CSS Classes ← نام کلاس را بدون نقطه بنویسید.

== کلاس‌های آماده ==
* darkbouttom  : سوییچ بین حالت روشن و تاریک.
* Lightmodebtn : فقط به حالت روشن می‌رود (اگر از قبل روشن بود پیام نشان می‌دهد).
* Darkmodebtn  : فقط به حالت تاریک می‌رود (اگر از قبل تاریک بود پیام نشان می‌دهد).
* Lightshow    : المنت فقط در حالت روشن دیده می‌شود و در دارک‌مود مخفی است.
* Darkshow     : المنت فقط در حالت تاریک دیده می‌شود و در حالت روشن مخفی است.

نمونه: لوگوی تیره را با کلاس Lightshow و لوگوی سفید را با کلاس Darkshow بگذارید.
در ویرایشگر المنتور هر دو دیده می‌شوند (با کادر خط‌چین) تا بتوانید ویرایششان کنید.

پیام دکمه‌های Lightmodebtn و Darkmodebtn از تب «پیام‌ها» تغییر می‌کند. روی هر دکمه می‌توانید ویژگی data-darkso-msg بگذارید تا پیام اختصاصی داشته باشد.

== ویجت‌های المنتور (دسته Darkso) ==
* سوییچ دارک‌مود: دکمه آیکنی با ۴ انیمیشن (چرخش، محو، سه‌بعدی، اسکیل).
* تصویر / متن / عنوان / آیکن لایت-دارک: برای هر حالت محتوای جدا. اگر یک حالت خالی باشد، حالت دیگر استفاده می‌شود.
* منوی وردپرس لایت / دارک: دو منوی جدا برای دو حالت.
* باکس آیکن: آیکن + عنوان + توضیح + دکمه؛ آیکن جدا برای دارک‌مود، رنگ‌ها در دو تب روشن و تاریک.
* نوشته‌ها (Post): چهار چیدمان (کلاسیک، روی تصویر، لیستی، مینیمال)، ستون واکنش‌گرا و صفحه‌بندی.
* Loop Grid: گرید نوشته‌ها؛ می‌توانید یک قالب ذخیره‌شده المنتور را برای هر آیتم انتخاب کنید.
* Loop Carousel: کروسل نوشته‌ها با فلش، نقطه، پخش خودکار، توقف با هاور و پشتیبانی RTL.
* پورتفولیو: گرید یا ماسونری، فیلتر دسته‌ها، افکت هاور و لایت‌باکس.
* فرم: فیلدهای دلخواه، ارسال AJAX، ایمیل و ذخیره پیام‌ها.

== کوئری ویجت‌های نوشته (Post / Loop Grid / Loop Carousel / پورتفولیو) ==
نوع نوشته، دسته یا برچسب، تعداد، رد کردن چند آیتم اول، مرتب‌سازی، حذف نوشته‌ی جاری و فقط نوشته‌های دارای تصویر شاخص.

== فرم ==
* فیلدها: متن، ایمیل، تلفن، عدد، متن بلند، لیست کشویی و چک‌باکس؛ عرض هر فیلد ۱۰۰٪ / ۵۰٪ / ۳۳٪.
* ایمیل گیرنده و موضوع را تنظیم کنید (پیش‌فرض: ایمیل مدیر سایت).
* با فعال بودن «ذخیره پیام در پیشخوان»، پیام‌ها در منوی «پیام‌های فرم» نمایش داده می‌شوند.
* محافظت از اسپم: فیلد مخفی (Honeypot)، محدودیت ۵ ارسال در دقیقه برای هر IP و Nonce تازه برای هر ارسال (سازگار با کش صفحه).
* اگر ایمیل‌ها نمی‌رسند، یک افزونه SMTP نصب کنید.

== عیب‌یابی ==
* تغییرات دیده نمی‌شود: کش سایت و کش CSS المنتور (Regenerate CSS) را پاک کنید.
* رنگی تبدیل نمی‌شود: کد رنگ را دقیقاً مطابق رنگ واقعی المنت اضافه کنید (#fff و #ffffff یکسان هستند؛ rgb و rgba هم تشخیص داده می‌شوند).
* Lightshow / Darkshow کار نمی‌کند: کلاس را بدون نقطه و با حرف اول بزرگ بنویسید.
* ویجت‌ها در المنتور نیستند: افزونه المنتور فعال باشد و ویرایشگر را یک بار رفرش کنید.
